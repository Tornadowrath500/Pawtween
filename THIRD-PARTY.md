# Third-party software

## FFmpeg (desktop version only)
The desktop installer bundles an unmodified FFmpeg executable, run as a separate
program for video export. FFmpeg is licensed under the GNU GPL v3 (this build
includes GPL components such as x264/x265).

- Build used: https://github.com/BtbN/FFmpeg-Builds (ffmpeg-master-latest-*-gpl)
- FFmpeg source and license: https://ffmpeg.org/legal.html and https://github.com/FFmpeg/FFmpeg
- Build scripts and corresponding source: https://github.com/BtbN/FFmpeg-Builds

Pawtween's own code is not a derivative of FFmpeg and remains MIT licensed.
The web version does not use FFmpeg.
